# Contributing to Zenoforge

Thanks for helping. Zenoforge is source-available: free for personal, noncommercial use, with commercial licenses sold by the maintainer (see [LICENSE](LICENSE)).

## Before your first pull request

Sign the [Contributor License Agreement](CLA.md). When you open a pull request, the CLA bot posts a comment; reply with the sentence it asks for. You only sign once.

## Pull requests

- One change per pull request, with a short description of what it fixes or adds and how you tested it.
- Put new host- or model-specific values in configuration rather than code.
- Never commit credentials.

## Reporting security issues

Do not open a public issue. Report the problem privately as described in [SECURITY.md](SECURITY.md).
